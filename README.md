# Casinow

Casino hors ligne au style Maison Noire (Art déco), entièrement dessiné et composé en code : blackjack, roulette, machines à sous, cartes à collectionner.

En ligne : https://floriandaunay.github.io/casinow/

```
npm install
npm run dev   # http://localhost:5180
npm test
npm run build
```

Chaque push sur `main` est testé, construit et publié sur GitHub Pages (`.github/workflows/deploy.yml`).
